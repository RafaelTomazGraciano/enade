## Explicação

Estruturas de dados lineares organizam elementos em sequência. As principais são:

**Fila**
- Segue o princípio FIFO (First In, First Out): o primeiro a entrar é o primeiro a sair

**Pilha**
- Segue o princípio LIFO (Last In, First Out): o último a entrar é o primeiro a sair

**Deque (Double Ended Queue)**
- Permite inserção e remoção nas duas extremidades da sequência
- É uma generalização da fila e da pilha

**Lista Simplesmente Ligada**
- Cada elemento contém um valor e uma referência (ponteiro) para o próximo elemento
- A ordem é determinada por essas referências, não por posição física na memória

**Lista Duplamente Ligada**
- Similar à lista simplesmente ligada, mas cada elemento aponta tanto para o próximo quanto para o anterior
