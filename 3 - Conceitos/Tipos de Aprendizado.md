# Tipos de Aprendizado
---
## Área de Estudo: Aprendizado de Máquina
---
## Explicação

O aprendizado de máquina é uma área da inteligência artificial em que
sistemas aprendem a partir de dados, sem serem explicitamente
programados para cada tarefa. O princípio central é a **indução**:
a partir de exemplos particulares, o modelo gera conclusões genéricas
que podem ser aplicadas a novos dados.

**Aprendizado Supervisionado**
- O modelo é treinado com dados que já possuem respostas corretas
  (rótulos ou valores de saída conhecidos)
- O erro é calculado como a diferença entre a saída gerada pelo modelo
  e a saída correta esperada
- Após o treinamento, o modelo consegue fazer previsões para novos dados
- Exemplos de algoritmos: regressão linear, regressão logística,
  árvores de decisão, redes neurais com supervisão

**Aprendizado Não Supervisionado**
- O modelo é treinado com dados que não possuem respostas de referência
- O objetivo é descobrir padrões, agrupamentos ou estruturas nos dados
- Não existe uma saída correta para comparar, portanto não há cálculo
  de erro da forma tradicional
- Muito utilizado quando se quer entender os dados por meio de
  reconhecimento de padrões
- Exemplos de algoritmos: K-means (clusterização), PCA (redução de
  dimensionalidade)
