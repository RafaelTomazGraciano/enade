# Interfaces Adaptativas
---
## Área de Estudo: Interação Humano-Computador (IHC)
---
## Explicação

Interfaces adaptativas são interfaces que se ajustam automaticamente
ao perfil, comportamento e preferências do usuário durante a navegação,
tornando a interação mais natural e eficiente.

**Os três níveis de adaptação**

**1. Adaptação de Conteúdo**
Altera o que é apresentado ao usuário, modificando ou filtrando
o conteúdo da página conforme seu perfil.
Técnicas:
- Fragmentos de texto: exibe trechos diferentes para perfis diferentes
- Fragmentos condicionais: mostra ou oculta blocos de conteúdo com
  base em condições do perfil do usuário
- Páginas variantes: versões diferentes de uma mesma página para
  perfis distintos
- Abordagem baseada em frames: organiza o conteúdo em quadros
  adaptáveis

**2. Adaptação de Navegação**
Altera a estrutura de links e caminhos disponíveis ao usuário,
guiando ou restringindo sua navegação.
Técnicas:
- Orientação direta: sugere ou redireciona o usuário para caminhos
  mais adequados ao seu perfil
- Anotação de links: adiciona informações visuais aos links para
  orientar a navegação
- Apresentação e ocultação de links: mostra ou esconde links conforme
  o perfil do usuário
- Ordenação de links: reorganiza a ordem dos links conforme preferências
  ou histórico do usuário

**3. Adaptação de Apresentação**
Altera a forma como o conteúdo é visualmente organizado e exibido.
Técnicas:
- Layouts de página: reorganiza a disposição visual dos elementos
- Guias de estilos: aplica diferentes estilos visuais conforme o
  perfil do usuário

**Ponto importante**
Para não confundir os três níveis.
O ponto-chave é:
- Conteúdo: o que é mostrado
- Navegação: por onde o usuário pode ir
- Apresentação: como o conteúdo é visualmente exibido
