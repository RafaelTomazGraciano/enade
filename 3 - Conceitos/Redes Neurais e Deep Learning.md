## Explicação

Uma rede neural profunda é composta por camadas de neurônios artificiais que aprendem padrões a partir de dados de treinamento. Os principais conceitos para entender o desempenho de uma rede são:

**Acurácia**
Mede o quanto a rede acerta nas suas previsões. Pode ser melhorada por:
- Adicionar mais camadas (rede mais profunda)
- Adicionar mais neurônios por camada
- Aumentar o volume de dados de treinamento
- Usar arquiteturas especializadas para o tipo de dado

**Tempo de treinamento**
Tempo necessário para a rede ajustar seus parâmetros. É aumentado por:
- Mais camadas
- Mais neurônios por camada
- Mais dados de treinamento

**Tipos de redes neurais**
- **CNN (Rede Neural Convolucional):** especializada em imagens, identifica
  padrões visuais como bordas, formas e texturas. Exige alto poder
  computacional.
- **RNN (Rede Neural Recorrente):** especializada em dados sequenciais,
  como texto e áudio. Não é adequada para classificação de imagens.
